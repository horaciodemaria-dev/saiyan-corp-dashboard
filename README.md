# SaiyanCorp Dashboard

A workforce analytics dashboard built with Next.js, React, TypeScript, and Recharts. It displays employee metrics and interactive charts using a deterministic, fictional dataset of 1,000 employees.

## Requirements

- Node.js 18.17 or later
- npm

## Getting started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Available scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run start` — serve the production build

## Data

The app generates sample employee data in memory; it does not connect to a real HR system or database. The employee API supports dashboard filters and returns aggregate statistics.
